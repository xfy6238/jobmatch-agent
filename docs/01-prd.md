# 求职 Agent · PRD（开源示例版 v0.1）

> 原则：只做能演示的匹配诊断 + 模拟面试，不做自动投递。
> 数据：`data/sample_jobs.json`（20 条虚构样例）。换成你自己的 JD JSON 即可复用全部链路。

## 1. 背景与目标

- 求职者面对一堆岗位 JD，人工筛选慢，且看不出“简历差在哪”。
- 目标：输入一句话画像/一份简历，输出 Top3 匹配岗位 + 缺口分析 + 模拟面试，5 分钟可演示。

## 2. 用户与场景（只做 2 个）

- S1 匹配诊断：“推 3 个最匹配的岗，并告诉我缺什么。”
- S2 模拟面试：“按这个 JD 面我 5 道题，打分并给改进。”

## 3. 功能需求

### Skill-1 匹配诊断

- 输入：简历文本/一句话画像（如默认 `3年 Python后端 + RAG问答项目 + LangChain + Docker部署`）+ 可选筛选（区域/薪资≥17K/活跃度）。
- 处理：画像 → 检索 JD 库 → 本地工具（薪资中位/活跃度/fit 规则）排序 → 缺口分析。
- 输出：Top3（标题+公司+薪资+活跃度+链接）+ 匹配理由 + 缺口（RAG/Prompt/MCP/部署等）+ 1 句改简历建议。

### Skill-2 模拟面试

- 输入：指定 1 个 JD（URL 或标题）。
- 处理：读该 JD + 同类高频点 → 出 5 道题 → 逐题作答 → 按要点打分。
- 输出：5 道题 + 参考要点 + 评分 + 改进 + 追问。

## 4. 非目标（明确不做）

- 不做自动投递/自动开聊（合规风险，且讲不清）。
- 不做账号系统（本地单用户）。
- 不含任何爬虫：数据由你自己提供，样例为虚构。

## 5. 数据需求

- 主库：JD 数组（字段见 `data/README.md`），开箱 20 条虚构样例。
- 画像：默认示例画像，可被输入覆盖。
- 详情 JD 正文为可选项：有则热点/出题更准（`BOSS_DETAILS`/`LIEPIN_DETAILS` 环境变量），无则回退标题+技能扫描。

## 6. 验收标准（演示即验收）

- A1：输入默认画像，返回 Top3 且每条带引用（标题+公司+薪资），缺口命中 RAG/Prompt/MCP 至少其一。
- A2：指定任一样例 JD，能出 5 道题并完成一轮追问打分。
- A3：公司名含“某”/“—”占位的条目默认不出；17K 以下默认不出现（`min_mid` 可调）。
- A4：无 API Key 也能跑通检索+规则排序（`rules` 降级模式），`backend/eval.py` 10 题应 10/10。
